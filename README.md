# freshhands

**Hire a freelancer. Get it done this week.**

freshhands is a simple place to find freelancers for small jobs: design, video editing, websites, game dev, music, writing, translation and tutoring. Beginners, students and pros. You message them directly. 0% commission.

**Live:** https://jenyatank.github.io/freshhands/

## What you can do

- **Find someone.** Search by skill or category. Search understands typos, transliteration and many languages ("dizain", "сайт", "diseño", "设计").
- **Create a free profile.** It goes live right away. Pick a category or write your own.
- **Chat on the site.** Reply, edit, copy, delete and select messages (right click, or long press on a phone).
- **Deliver work safely.** The freelancer uploads the file. The client sees a watermarked, view-only preview and pays the freelancer directly. The download unlocks after the freelancer confirms the payment.
- **Pick a theme.** Four looks at the bottom of the page.

## Safety

- freshhands never holds money. Clients pay freelancers directly.
- Swearing and adult words are blocked in profiles and chats.
- Three reports hide a profile automatically.
- You must be 13 or older. Under 18, a parent should know.

## Built with

One `index.html` and a `data.js` settings file, hosted on GitHub Pages, with a Supabase database. No frameworks.
